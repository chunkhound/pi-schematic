# Tested behaviour

A change to the extension's behaviour comes with added or updated tests for that behaviour, or with an entry for it in the "Untested behaviour" list of `CONTRIBUTING.md`. An entry for a deliberate choice says so and gives the reason; an entry without that is a gap.
