# Changelog

`CHANGELOG.md` has one `[Unreleased]` section. A change that changes what a user or another extension sees (a feature, a fix, a raised requirement) adds its entries under `[Unreleased]`; a change that only changes tests, tooling, CI or contributor documentation adds none. An entry that removes or changes something a user or another extension can rely on is listed under Breaking Changes.
